# 🎬 Netflix & Movies Data Analysis Dashboard

## Project Overview

This project analyzes movie and Netflix content data using Python and Power BI. The goal is to transform raw data into meaningful insights by performing data cleaning, exploratory data analysis (EDA), and interactive dashboard development.

The project helps identify trends in content distribution, ratings, genres, release patterns, and audience engagement through data visualization and reporting.

---

## Objectives

- Clean and prepare raw datasets for analysis.
- Perform exploratory data analysis to uncover trends and patterns.
- Analyze content by genre, ratings, popularity, and release year.
- Build an interactive Power BI dashboard for data exploration.
- Generate insights that support data-driven decision-making.

---

## Dataset

The dataset contains information such as:

- Title
- Genre
- Release Year
- Rating
- Popularity Score
- Vote Count
- Content Type (Movie/TV Show)

After preprocessing, the dataset was prepared for analysis and dashboard development.

## How to Run the Project

### Clone the Repository

```bash
git clone https://github.com/kartik-kgn/netflix-movies-data-analysis.git
```

### Install Dependencies

```bash
pip install pandas numpy matplotlib seaborn
```

### Run the Analysis

```bash
jupyter notebook
```

Open `Netflix_DA.ipynb` and run all cells.

### Open the Dashboard

1. Open `Netflix_Dashboard.pbix` in Power BI Desktop.
2. Refresh the dataset if required.
3. Explore the dashboard using filters and slicers.
